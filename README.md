# AccessiDemo 

Aplicación React Native que demuestra las **mejores prácticas de accesibilidad** según WCAG 2.1.

**Presentación:** https://canva.link/0dz9z9zwa90hzzq

---

##  Funciones Principales

### 1.  **TalkBack / Screen Reader** 
Soporte completo para lectores de pantalla con etiquetas, anuncios en vivo y roles semánticos para usuarios ciegos o con baja visión.

### 2.  **Modos de Tema** 
Tres modos de color: Claro, Oscuro y Alto Contraste. Validación automática de ratios WCAG (mínimo 4.5:1 para AA, 7:1 para AAA).

### 3.  **Escala de Texto Dinámica** 
Cuatro niveles de escalado (×0.85, ×1.0, ×1.25, ×1.5) sin pérdida de contenido. Soporta escalado hasta 200%.

### 4.  **Configuración Centralizada**
Panel de control para ajustar temas, tamaño de fuente, texto en negrita, anillo de foco y badges WCAG. Preferencias persistentes.

### 5.  **Características Adicionales**
- Retroalimentación háptica para acciones
- Anillo de foco visible (WCAG 2.4.7)
- Opción de reducir movimiento (WCAG 2.3.3)
- Indicadores WCAG educativos
